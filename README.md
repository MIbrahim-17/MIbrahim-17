## About Me

I'm a **Computer Science student at Lahore University of Management Sciences (LUMS)** and an **AI for Software Engineering researcher**.

My work focuses on applying **AI, LLMs, and autonomous agents to software engineering**, particularly in development, testing, CI/CD, and software maintenance.
